1. 为什么不同项目最好使用不同的 Python 虚拟环境？
- 不同项目依赖的库版本不一样，有可能安装新版本会导致旧版本被覆盖，导致另一个项目报错

2. CPU 和 GPU 各自擅长什么？训练神经网络为什么经常使用 GPU？
- CPU：擅长逻辑判断，处理任务灵活，但并行计算核心数量少
- GPU：擅长大规模、简单、可以并行执行的数值运算

- 神经网络本质是大量矩阵、张量并行计算，用GPU可以加快训练速度

3. CUDA 是什么？它、显卡驱动与 PyTorch 之间大致是什么关系？
- CUDA是NVDIA推出的并行计算平台和编程模型，让开发者可以直接用N卡做数值计算
- 关系：显卡驱动负责操作系统和硬件沟通，是一切的底层基础，CUDA是在显卡驱动之上，提供GPU并行计算的API，PyTorch是深度学习框架，调用CUDA接口，把张量计算给GPU执行
