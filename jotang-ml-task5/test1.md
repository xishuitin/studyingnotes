# 传统图像分类模型需要怎样的数据？CLIP 为什么选择使用互联网上的 “图片 — 文字” 对进行训练？

1. 需要人工标注好的数据集，每张图片人工打上类别标签
2. 
- 互联网的图片数据多且免费，自然语言描述的正确，不需要人工标注
- 自然语言包括了很多语义信息，比类别标签更好
- 学习图文对齐，模型可以零样本分类

# CLIP 由哪两个编码器组成？图片和文字经过编码器以后分别变成了什么？

1. 图像编码器和文本编码器
2. 图像经过ResNet或者ViT转化为图像特征向量，图像嵌入
   文本经过Transformer转化为文本特征向量，文本嵌入

# 什么是图文对齐？为什么语义匹配的图片向量和文本向量应该更加接近？

1. 将图像、文本编码到同一个向量空间，语义上匹配的图像与文本，对应的向量相似度高；语义不匹配的向量相似度低。
2. 向量空间里向量距离代表语义相似度。如果图片内容和文本描述是同一个事物，语义一致，向量就应该靠近；语义不同，向量相互远离。、

# 结合论文 Figure 1，说明一个 batch 中的 N 张图片和 N 段文字怎样组成 \(N\times N\) 个配对，哪些是正样本，哪些是负样本。

1. 通过CrossEntropy,两两交叉组合
2. 
- 正：第i张图与第i条对应的文本对应，对角线配对，一共N个
- 负：其余所有非对角线配对，共N **2-N个

# CLIP 的训练目标是什么？它怎样让正确配对的相似度升高、错误配对的相似度降低？
1. 图文对比学习。最大化 batch 内匹配图文对的余弦相似度，最小化不匹配图文对的余弦相似度。使用交叉熵损失。
2. 
- 计算全部N * N图文对之间的余弦相似度，得到相似度矩阵；
- 让对角线相似度尽可能大；非对角线相似度尽可能小；
- 反向传播同时更新图像编码器、文本编码器参数，完成图文对齐学习。

# 论文中提到的 prompt engineering 是什么？dog 与 a photo of a dog 可能产生不同结果吗？

1. 在不修改权重参数的情况下，设计、调整输入prompt,优化零样本分类效果，设计不同句式
2. 文本编码器对完整句子理解更好。dog是单词，而后者是句子，更加贴近互联网图文描述分布，得到的质量更高

# CLIP 有哪些限制？互联网图文数据可能给模型带来哪些偏见或错误关联？这其中蕴含着如今大模型训练的什么重要思想（开放性题目）
1. 专业/抽象任务表现差，数据效率低，Few-shot性能不佳，OCR能力不稳定
2. 互联网图文存在社会偏见：性别、种族、职业刻板印象；部分图文存在错误标注、虚假关联。模型会学到数据里的错误相关性。
3. 大模型训练不只是堆算力，同时需要重视数据治理、偏见评估、模型安全与公平性。
