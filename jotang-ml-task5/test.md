# 为什么图片特征与文本特征可以计算相似度？两个编码器的输出需要满足什么条件？
1. 图像编码器、文本编码器把图像、文本映射到同一个维度、同一个共享高维向量空间。
2. 输出向量维度相同，就可以用余弦相似度衡量向量方向的接近程度。
# 为什么通常要先对特征做 L2 归一化？归一化后的点积与余弦相似度有什么关系？
- 归一化后，，消除模长影响，向量点积=余弦相似度，简化计算
# 为什么 CLIP 的训练损失会从两个方向计算？如果不这么设计会有什么问题？
1. 分别从图检索文本和文本检索图计算
2. 只单项计算，模型容易退化，可能图像只学到了一个固定向量
双向约束，让对齐更加均衡，增加图文对齐质量
# zero-shot 是否真的意味着模型从未见过相似内容？它与“不对当前任务进行训练”有什么区别？
1. 不是，Zero-shot 是没有见过该任务的标注样本，但训练数据里可能见过相关概念。
2. Zero-shot：预训练阶段见过概念，没有见过当前任务标注；直接推理，不更新权重；
  “不对当前任务训练” 范围更广，可能模型完全不懂任务里的概念，无法完成。
# CLIP 会在相似度上乘一个可学习的温度系数。这个系数变大或变小时，softmax 分布和模型对配对结果的“确信程度”会怎样变化？
1. 温度T，softmax(s/T)
2. T变大：输出分布更平滑，各类别概率差距缩小，模型确定性降低
T变小：分布更尖锐，最大概率类别权重被放大，模型对预测结果更确信
# 如果训练数据中“雪地”经常和“北极熊”同时出现，模型可能学到怎样的捷径？这种数据偏见会如何影响真实场景中的判断？
1. 看到雪地就预测北极熊，而不是识别动物本身。
2. 职业标签偏见：
女性更多："nanny", "housekeeper"
男性更多："prisoner", "mobster", "executive", "doctor"
