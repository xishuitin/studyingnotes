# 这篇论文最初处理的是什么任务？它为什么尝试不用 RNN 和 CNN?

1. 最开始的任务是：机器翻译，序列到序列
2. RNN：1.耗费长时间 2.并行能力弱，难以发挥GPU的并行能力 3.记忆会损失，难以形成远距离依赖
   CNN:CNN通过多层卷积扩大感受野，可以建模长距离依赖，但是和FNN有相同的缺点，无记忆能力，长距离依赖计算成本大；深层训练易梯度消失；原生要求输入尺寸固定；缺少动态聚焦关键信息的能力


<h1>Self-Attention 中的 “Self” 是什么意思？它和普通 Attention 有什么区别？

1.  Self：Q、K、V 全部来自同一个输入序列，让序列内部每个 token，去和同序列其他 token 计算相关性。
2. 普通 Attention（交叉注意力 Cross-Attention）：Q 来自目标序列（Decoder 侧），K、V 来自源序列（Encoder 侧），是两个不同序列之间做匹配查询。


# Q、K、V 分别来自哪里？它们为什么要经过不同的线性变换？
  1. 输入是相同的 token embedding 向量，分别乘三组独立的权重矩阵，得到 Q (Query 查询向量)、K (Key 键向量)、V (Value 值向量)
  2. 将原始 embedding 映射到相互独立的特征子空间，Q 学习 “查询需求”，K 学习 “被检索的标识”，V 保存需要提取的信息；
  如果共用一套线性层，QKV 向量完全一致，模型表达能力会大幅下降；


 # Attention 的结果为什么要经过 softmax？得到的每一行权重表示什么？

   1. 点积得到的相关性分数取值范围不受限，`softmax`将分数归一化为概率分布，一行所有权重相加等于 1。
   2. 每一行权重：当前 token 对序列中所有 token 的注意力权重。权重数值越大，代表当前单词越关注序列里对应的那个单词。

# Multi-Head Attention 为什么要分成多个头？多个头只是把同一件事重复多次吗？
  1. 不是简单重复计算,多头注意力将 Q/K/V 切分成多组，每组在独立的特征子空间单独做自注意力，最后拼接所有头的输出，再做线性融合
  2. 不同注意力头学习捕捉不同类型的语义依赖,单头只能在一个特征空间衡量词相关性；多头可以并行捕获多种关联模式，提升模型表达能力

# Transformer 没有循环结构，它怎样知道词语的先后顺序？
  Transformer 本身没有时序感知能力，依靠Positional Encoding 位置编码将预先设计的位置向量，直接加到词嵌入 embedding 上。位置编码根据 token 在序列中的位置生成独一无二的向量，把位置信息注入输入

# Decoder 中为什么需要 Masked Attention？如果能提前看到后面的答案，会发生什么？
  1. Masked Attention（掩码自注意力）：屏蔽未来时刻的 token。训练生成任务时，第 i 个 token 只能看到 1~i 位置的 token，不能看到 i 之后还未生成的 token。
  2. 如果不做掩码：训练阶段模型可以直接偷看目标序列后面的 token，模型不需要学习推理预测，直接复制未来 token 就能得到低损失。学到的能力无法泛化，推理阶段不能使用。

# 残差连接、Layer Normalization 和 Feed-Forward Network 分别出现在结构图的哪里？它们大致有什么作用？

  1. **残差连接** 
    位置：每一个子层（注意力模块、FFN 模块）的输入直接跨过子层，和子层输出相加。公式：x + Sublayer(x)
    作用：构建短路通路，缓解深度网络梯度消失，支持深层模型训练。
  2. **Layer Normalization层归一化**
    位置：放在注意力、FFN 子层计算完成之后。
    作用：对单个样本特征做归一化，稳定特征分布，加速训练收敛。
  3. **Feed-Forward Network**
    位置：多头注意力模块之后。
    作用：对每一个 token 独立做两层全连接非线性变换，在特征维度做映射，增强模型非线性表达能力；各个 token 之间互不干扰。
